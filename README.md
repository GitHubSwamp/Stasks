# To-Do List

A simple and interactive To-Do List built with **HTML, CSS, and JavaScript**.
Try at: https://githubswamp.github.io/Stasks/
## Features

* Add tasks
* Delete tasks
* Store tasks in the browser using Local Storage
* Tasks remain saved after refreshing the page
* Simple and responsive interface

## Technologies

* HTML5
* CSS3
* JavaScript
* Local Storage

## Purpose

This project was created to practice JavaScript fundamentals, DOM manipulation, event handling, arrays, and browser Local Storage.
